# Practical data science

Doing data science end to end in the cloud: preparing data, detecting bias, training and tuning models, and deploying them with managed services.

**Roles:** data scientist, ML engineer.
**Prerequisites:** [Machine learning](../machine-learning/)

> The Practical Data Science on AWS specialization I took is no longer offered: its DeepLearning.AI and Coursera pages return errors. The resources below cover the same ground.

## Key concepts

- **Explore and prepare data at scale.** Profile the data, handle missing values and outliers, and engineer features before modeling.
- **Check for bias.** Measure imbalance in the training data and in model predictions across groups, before and after training.
- **Automate where it helps.** AutoML gives a quick baseline and shows which models and features matter.
- **Train, tune and track.** Run training as repeatable jobs, search hyperparameters systematically, and record every experiment.
- **Deploy and monitor.** Serve models behind endpoints, run A/B tests between versions, and watch for data drift.
- **Human in the loop.** Use human review and labeling to improve data quality and handle low-confidence predictions.
